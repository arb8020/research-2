# ch01 gpt2 forward vs HuggingFace: measurements

> Historical evidence for the ch01 thresholds (assay/ch01/suite.py: KL_MAX; the per-op 2x-budget floors it also backed were replaced by allclose, suite.py TOL) and prompt choice (ops.py PROMPTS).
> The code that generated it (`measure/`, branch `engine/ch01-forward` at f461aea1) was folded into assay and removed:
> its metrics are ops.py's numerics, its mutants suite.py's MUTANTS, its prompts ops.py's texts. Raw jsonl: same commit.

Generated by `uv run python -m measure.run fp32`, `... bf16`, then `uv run python -m measure.report` (from `blogs/engine/ref/ch01`). Raw numbers: `measure/results-*.jsonl`. No thresholds; numbers only.

Reference: `GPT2LMHeadModel` (`openai-community/gpt2`, attn_implementation=eager, eval, no_grad) in the same dtype as ours. Greedy: HF decodes with its KV cache, ours recomputes the full sequence each step. KL is KL(HF || ours) per position, nats, float64. `logprobs_close` is vLLM's check: walk both greedy runs; at the first mismatch, pass iff each token is in the other's top-5. max rel is max |d| / |HF logit| (blows up on the few logits near zero; `max abs / max|HF|` is the scale-normalized alternative). Residual stream slots are captured with hooks on HF's blocks (pre-ln_f), not hidden_states.

Mutants (deliberate bugs, one-line edits of gpt2.py, see measure/mutants.py):

- `a_scale_1/hd`: attention scale 1/head_dim instead of 1/sqrt(head_dim) (`/ math.sqrt(hd)` -> `/ hd`)
- `b_no_ln_f`: final layer norm skipped (`final = layer_norm(residual_stream(w, cfg, tokens)[-1], w, "ln_f", cfg)` -> `final = residual_stream(w, cfg, tokens)[-1]`)
- `c_gelu_exact`: exact erf GELU instead of GPT-2's tanh approximation (`approximate="tanh"` -> `approximate="none"`)
- `d_mask_leak`: causal mask off by one: each query also sees the next key (`triu(diagonal=1)` -> `triu(diagonal=2)`)
