Rulings today (user, 2026-09-09) that this brief carries into code:
- Cache memory is ONE slab pool in Zig (Jenga / TokenSpeed). A slab is bytes. Each cache group carves pages of `bytes_per_page_g` out of slabs it owns. Reopens the 09-06 "LCM slabs not earned" ruling: the ladder is heterogeneous (gpt_oss F+W128, Kimi F+R, dsv4 five groups, DFlash draft group) and today's pool is one id space over N per-group tensors (bytes statically partitioned, worst of both).
- Recurrent / inplace state (GDN, KDA, dsv4 compress state) is a real `per_seq` cache group owned by Zig. `kelpie_models/state.py` (StateRing) and `groups.py:state_specs/StateSpec` are deleted at the end.
- Padding quantum 4 KB fixed; eviction = slab-LRU with mass hash drop of its pages (not page-LRU + compaction).
- Model declares the spec (`attn_specs` -> `groups.py`), Zig owns placement; kernels see `[num_pages_g, block_size_g, *unit]` views into one flat byte tensor. Survey basis: vLLM `MambaSpec`/`MambaManager`, SGLang `HybridReqToTokenPool`, TokenSpeed `CacheGroupSpec` family=state with window=2.

Steps (each its own commit(s) + trace):

1. Slab pool. `kv_pool.zig`: `Pool.init(num_slabs, slab_bytes, groups[])` where `groups[g] = {bytes_per_page, pages_per_slab = slab_bytes / bytes_per_page}`; `bytes_per_page` is the group's `block_size_g * sum(member bytes)` rounded up to 4 KB; `slab_bytes = lcm_g(bytes_per_page_g)` (assert <= a sane cap, STOP if any ladder model exceeds 64 MB). Slab free list is today's LRU list. Per group: a list of partially-filled slabs to carve from; `allocate(g, into)` pops pages from the group's partial slab, taking a fresh slab from the LRU head when empty; `free(g, ids)` returns pages, returns the slab to the LRU tail when its last page frees. Page id = (slab, index) packed in u32; block tables keep carrying page ids. Publish/lookup/touch stay per page. Eviction: allocate popping a slab from the LRU head drops the hash of every published page in it. Equal-bytes models (one group, or groups with equal `bytes_per_page`) must degenerate to `pages_per_slab == 1` and produce byte-identical traces (all 47).
2. Per-group `block_size`. `KelpieConfig.group_block_sizes` already exists per group; make it real (today `check_groups` asserts one block size across groups — delete that assert; `c_api.zig` stops requiring equality). `blocksFor`/`rowsFor`/prefix grain read `stride_g * block_size_g`. Trace: F block 16 + W128 block 16 + stride-4 group block 32.
3. Additive ABI: `KelpieConfig.group_bytes_per_page` (`[n_groups]`, NULL = legacy one-tensor-per-group mode must still work for one step of migration) and `kelpie_get_config` exposes `slab_bytes`, `num_slabs`. STOP if anything else is needed.
4. Recurrent as a per_seq group. Rules: (a) `group_windows[g]` allowed on per_seq (drop `c_api.zig` BadWindow); window = units kept = 2 + K (live + checkpoint + K+1 candidates when K>0; K=0 -> 2). (b) Live-slot rule: `slot_mapping[g][row]` for a per_seq group is the request's live unit for EVERY row (per_token would give null off-boundary); at a checkpoint boundary (`stride_g = S`, position % S == S-1) open a new unit, old live becomes the checkpoint, window frees the one before -> null. S = 0 means never checkpoint (one live unit, window 1). (c) Prefix hit: hash checkpoint units like any stride-S page when `cacheable`; on hit the request reads the shared checkpoint and gets a FRESH live unit (assert write != read). `prefix.zig:31,115` per_seq skips go away. (d) Drafts: reserve K+1 units, commit(accepted) keeps unit `accepted`, frees the rest, no copy. Traces: per_seq S=0 (byte-identical to today's one-block-per-request), S=16 window 2 across a boundary, hit at a checkpoint, K=4 accepted=3.
5.
